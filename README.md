# Nima Nouri — Portfolio

نسخهٔ اصلاح‌شدهٔ پورتفولیو با حفظ فضای ربات‌ها و انرژی خورشیدی.
اطلاعات تحصیلی و پروژه‌ها بر اساس رزومهٔ موجود در همین بسته تکمیل شده‌اند.

## مشاهدهٔ سایت

۱. تمام محتوای ZIP را از حالت فشرده خارج کنید.
۲. فایل `index.html` را در مرورگر باز کنید.
۳. پوشهٔ `assets`، فایل `styles.css` و فایل `script.js` باید کنار `index.html` بمانند.

سایت کاملاً ایستا است و برای نمایش محلی به نصب، ساخت پروژه یا دریافت فونت و کتابخانه از اینترنت نیاز ندارد. لینک ایمیل و GitHub طبق معمول به برنامهٔ ایمیل و اینترنت متکی هستند.

برای ویرایش در VS Code می‌توانید از Live Server استفاده کنید. برای GitHub Pages نیز فایل‌ها را با همین ساختار در ریشهٔ محل انتشار قرار دهید.

## اصلاحات

- تمام نوشته‌ها، منوها و دکمه‌های حک‌شده در تصویر پس‌زمینه حذف شده‌اند.
- متن و دکمه‌های صفحهٔ اول از عناصر واقعی HTML ساخته شده‌اند.
- لایه‌های محوکننده و پنل‌های پنهان نسخهٔ قبلی حذف شده‌اند.
- قاب تصویر و جای متن در موبایل مستقل از دسکتاپ تنظیم شده است.
- حرکت ملایم پس‌زمینه روی دسکتاپ اعمال می‌شود. متن و دکمه‌ها ثابت‌اند.
- با فعال بودن کاهش حرکت در تنظیمات دستگاه، افکت‌های حرکتی غیرفعال می‌شوند.
- منوی موبایل با کلیک بیرون، انتخاب لینک و کلید Escape بسته می‌شود.
- مشخصات تحصیلی، هشت درس منتخب، مهارت‌ها، زبان‌ها و فعالیت ورزشی از رزومه تطبیق داده شده‌اند.
- دو پروژهٔ اصلی و پنج پروژهٔ دیگر ارائه شده‌اند. برای مشاهدهٔ جزئیات پنج پروژهٔ دیگر روی عنوان آن‌ها بزنید.
- همهٔ محتوا، لینک‌ها و بازشدن جزئیات پروژه‌ها بدون JavaScript نیز در دسترس‌اند.
- کلید Tab برای جابه‌جایی میان لینک‌ها و دکمه‌ها قابل استفاده است.
- تصاویر WebP برای بارگذاری سبک‌تر به‌همراه نسخه‌های PNG داخل بسته هستند.

## کنترل نهایی

نمایش در مرورگر Chromium در عرض‌های ۳۲۰، ۳۶۰، ۳۹۰، ۴۳۰، ۶۰۰، ۷۶۸، ۹۰۰، ۹۰۱، ۱۰۲۴، ۱۳۶۶، ۱۴۴۰ و ۱۹۲۰ پیکسل بررسی شد. اسکرول افقی، مسیر فایل نامعتبر یا خطای JavaScript شناسایی نشد. منو، کلید Escape، پیمایش با صفحه‌کلید، بازشدن پروژه‌ها، کپی ایمیل، حالت بدون JavaScript و تنظیم کاهش حرکت بررسی شدند. بررسی خودکار دسترس‌پذیری با axe-core مورد خطایی گزارش نکرد. تصاویر پیش‌نمایش دسکتاپ و موبایل در پوشهٔ `previews` قرار دارند.
